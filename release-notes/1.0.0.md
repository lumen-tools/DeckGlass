DeckGlass 1.0 – RetroArch and Retro Crisis shaders for every game on the Steam Deck, via gamescope ReShade.

The plugin is the same as 0.9.0; this release marks DeckGlass as stable.

### Highlights
- RetroArch slang presets (multi-pass, feedback, history, LUTs, parameters) converted to one ReShade effect right on the Deck
- Shader browser with RetroArch, Retro_Crisis and Custom_Shaders
- Source resolution presets (240p, 480i/p, handhelds) with 720p/800p values, plus a manual pixel size
- Bilinear filtering (averages each original pixel's area, on by default)
- Per-game settings and save states as files in `~/DeckGlass/Save_States`

### Install
Download `DeckGlass-1.0.0.zip` below → Decky → Developer → **Install Plugin from ZIP**.

DeckGlass is an independent project inspired by ShaderGlass; it contains no ShaderGlass code and is not affiliated with it.
