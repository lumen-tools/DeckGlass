Beta update.

### Changed
- **Round pixel sizes for system presets.** The exact fit on the 1280×800 screen is rarely a round number (SNES: 800 / 224 = 3.57×). Fractional factors make scanlines alternate in thickness and cause visible banding, so every system preset now uses a round pixel size close to the exact fit:

| System | Resolution | Pixel size |
|---|---|---|
| NES / Famicom | 256×240 | 3× |
| SNES | 256×224 | 4× |
| Mega Drive / Genesis | 320×224 | 4× |
| Master System | 256×192 | 4× |
| PC Engine | 256×232 | 3× |
| Nintendo 64 | 320×240 | 3× |
| PlayStation | 320×240 | 3× |
| PlayStation (480i) | 640×480 | 1.5× |
| Saturn | 320×224 | 4× |
| Dreamcast | 640×480 | 1.5× |
| PlayStation 2 | 640×448 | 2× |
| GameCube / Wii | 640×480 | 1.5× |
| Arcade (CPS) | 384×224 | 3× |
| Game Boy / Color | 160×144 | 6× |
| Game Boy Advance | 240×160 | 5× |
| Nintendo DS (one screen) | 256×192 | 4× |
| PSP | 480×272 | 2.5× |
| Game Gear | 160×144 | 6× |
| Neo Geo Pocket | 160×152 | 5× |
| WonderSwan | 224×144 | 6× |

Use **Manual** if you want a different value.
