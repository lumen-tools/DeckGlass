### Changed
- **Save states are now files:** each save state is its own file in `~/DeckGlass/Save_States/<name>.json` – easy to back up, copy to another Deck or share. They also survive uninstalling the plugin. Copy files into the folder and they show up in the Save States list.
- Existing save states are moved there automatically on the first start, with the same names (characters that cannot be in a file name, such as `/`, become `-`). Per-game settings keep pointing to their save state. A copy of the old settings is kept as `~/DeckGlass/settings-before-0.9.json`.

### Install
Download `DeckGlass-0.9.0.zip` below → Decky → Developer → **Install Plugin from ZIP**.
