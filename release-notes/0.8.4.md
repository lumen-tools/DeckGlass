### Changed
- **Manual pixel size is applied with a button.** Moving the slider only changes the shown value; **Apply pixel size** takes it over – one recompile instead of several while sliding.
- **The compile notice appears once per shader**, the first time a change makes gamescope compile it. It comes again after choosing another shader. Starting a game with per-game settings never shows it.

### Install
Download `DeckGlass-0.8.4.zip` below → Decky → Developer → **Install Plugin from ZIP**.
