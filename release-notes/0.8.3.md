### Changed
- **Notice before the picture pauses.** Whenever the active shader changes in a game (or globally), gamescope compiles it and the whole picture – including the menu – pauses until it is done. DeckGlass now shows a notice first, so it is clear that nothing has crashed. Small shaders take a moment, big ones like Retro Crisis longer; best set the shader up before starting the game.
- **Fewer recompiles:** parameter changes are collected and applied together when you press **Apply** or close the parameter dialog, instead of after every slider movement.
- **Faster compile for Retro Crisis and other shaders with a computed mip level:** the emulated mip chain needs 5 instead of 11 extra passes (Retro Crisis: 26 instead of 32 passes). The picture is identical.
