### Changed
- **Pixel sizes use at most one decimal** (e.g. 3.3 instead of 3.33). The detection of 720 or 800 lines stays:

| System | Game renders 720 lines | Game renders 800 lines |
|---|---|---|
| 240p | 3× | 3.3× |
| 480i/p | 1.5× | 1.7× |
| Game Boy / Color, Game Gear, WonderSwan | 5× | 5.6× |
| Game Boy Advance | 4.5× | 5× |
| Nintendo DS | 3.8× | 4.2× |
| PSP | 2.6× | 2.7× |
| Neo Geo Pocket | 4.7× | 5.3× |

- The manual pixel size slider moves in steps of 0.1.

### Install
Download `DeckGlass-0.4.3.zip` below → Decky → Developer → **Install Plugin from ZIP**.
