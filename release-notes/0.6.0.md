### New source resolution
- **Presets based on the CRT raster:** **240p** (NES, SNES, Mega Drive, PS1, N64, Saturn, Arcade), **480i/p** (PS2, GameCube, Wii, Dreamcast) and handhelds with their real screens.
- **The pixel size follows from the real height of the game picture.** DeckGlass detects whether the emulator renders 720 or 800 lines, so 240p always gets 240 lines and 480i/p 480 lines.
- **Black bars top & bottom:** turn it on if you see black bars above and below the game.
- Saved settings and per-game profiles are carried over.

### Install
Download `DeckGlass-0.6.0.zip` below → Decky → Developer → **Install Plugin from ZIP**.
