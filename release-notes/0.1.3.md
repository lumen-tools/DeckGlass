Beta update.

### New
- **"Black bars top & bottom" switch** under Source Resolution. Emulators differ on the 16:10 Deck screen: some fill the screen height (800 lines), others show a 16:9 area with bars at the top and bottom (720 lines). Turn the switch on when you see bars – the pixel sizes adjust automatically. Like everything else, it can be stored per game.

| System | Resolution | No bars (800) | Bars (720) |
|---|---|---|---|
| NES / Famicom | 256×240 | 3× | 3× |
| SNES | 256×224 | 4× | 3× |
| Mega Drive / Genesis | 320×224 | 4× | 3× |
| Master System | 256×192 | 4× | 4× |
| PC Engine | 256×232 | 3× | 3× |
| Nintendo 64 | 320×240 | 3× | 3× |
| PlayStation | 320×240 | 3× | 3× |
| PlayStation (480i) | 640×480 | 1.5× | 1.5× |
| Saturn | 320×224 | 4× | 3× |
| Dreamcast | 640×480 | 1.5× | 1.5× |
| PlayStation 2 | 640×448 | 2× | 1.5× |
| GameCube / Wii | 640×480 | 1.5× | 1.5× |
| Arcade (CPS) | 384×224 | 3× | 3× |
| Game Boy / Color | 160×144 | 6× | 5× |
| Game Boy Advance | 240×160 | 5× | 4.5× |
| Nintendo DS (one screen) | 256×192 | 4× | 4× |
| PSP | 480×272 | 2.5× | 2.5× |
| Game Gear | 160×144 | 6× | 5× |
| Neo Geo Pocket | 160×152 | 5× | 5× |
| WonderSwan | 224×144 | 6× | 5× |

All values are round (x.5 only where exact), so every scanline stays equally thick.
