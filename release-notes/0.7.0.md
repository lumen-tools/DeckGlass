### Changed
- **Calmer pixel sizes:** system presets use at most one decimal, while the detection of 720 or 800 lines stays:

| System | Game renders 720 lines | Game renders 800 lines |
|---|---|---|
| 240p | 3× | 3.3× |
| 480i/p | 1.5× | 1.7× |
| Game Boy / Color, Game Gear, WonderSwan | 5× | 5.6× |
| Game Boy Advance | 4.5× | 5× |
| Nintendo DS | 3.8× | 4.2× |
| PSP | 2.6× | 2.7× |
| Neo Geo Pocket | 4.7× | 5.3× |

- **Manual pixel size** accepts any value in steps of 0.01 – small screens can show slight mosaic patterns, so try nearby values until it looks right.
