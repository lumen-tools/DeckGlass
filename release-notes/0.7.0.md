DeckGlass – RetroArch and Retro Crisis shaders for every game on the Steam Deck, via gamescope ReShade. Not 1.0 yet: it works well in testing, but expect rough edges.

### Features
- Converts RetroArch slang presets (`.slangp`) into one ReShade effect right on the Deck – multi-pass, feedback, history, LUTs, parameters, and emulated mipmaps (gamescope has none)
- File browser with three libraries: **RetroArch** (libretro slang-shaders), **Retro Crisis** (incl. "720p Steam Deck") and **Custom** (`~/deckglass-shaders`, e.g. for a newer Retro Crisis release or presets saved in RetroArch)
- **Source resolution:** **240p** (NES, SNES, Mega Drive, PS1, N64, Saturn, Arcade), **480i/p** (PS2, GameCube, Wii, Dreamcast) or a handheld. DeckGlass detects whether the emulator renders 720 or 800 lines and picks a pixel size with at most one decimal:

| System | Game renders 720 lines | Game renders 800 lines |
|---|---|---|
| 240p | 3× | 3.3× |
| 480i/p | 1.5× | 1.7× |
| Game Boy / Color, Game Gear, WonderSwan | 5× | 5.6× |
| Game Boy Advance | 4.5× | 5× |
| Nintendo DS | 3.8× | 4.2× |
| PSP | 2.6× | 2.7× |
| Neo Geo Pocket | 4.7× | 5.3× |

- **Black bars top & bottom:** turn it on if you see black bars above and below the game
- **Manual pixel size** in steps of 0.01 – small screens can show slight mosaic patterns, so try nearby values until it looks right
- **Bilinear filtering** of the game image (on by default)
- **Per-game settings**, "Only in games" mode, parameter dialog that explains numbered values
- Optional **OLED defringe** (Deck OLED only)
- **Crash guard:** a shader that crashes gamescope is turned off automatically

### Earlier milestones
- **0.5** – first regular release: converter, file browser with RetroArch, Retro Crisis and Custom, per-game settings, bilinear filtering, emulated mipmaps
- **0.6** – new source resolution based on the 240p / 480i raster with automatic detection of 720 or 800 lines

### Install
1. Enable developer mode in Decky.
2. Download `DeckGlass-0.7.0.zip` below.
3. Decky → Developer → **Install Plugin from ZIP**.

### Known limitations
- Some RetroArch presets cannot be converted (the plugin shows an error).
- Heavy presets (e.g. Retro Crisis) cost GPU time and add some latency; gamescope also has to composite every frame while an effect is active.
- Screenshots do not include the shader.
