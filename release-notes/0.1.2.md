Beta update – replaces 0.1.1.

### Fixed
- **System presets are now based on 720p.** Emulators on the Steam Deck normally show the game in a 1280×720 area (16:9, with bars on the 16:10 screen). 0.1.1 wrongly assumed the full 800 lines. Pixel sizes are now based on 720 lines, which makes most of them exact and round:

| System | Resolution | Pixel size | Lines |
|---|---|---|---|
| NES / Famicom | 256×240 | 3× | 240 |
| SNES | 256×224 | 3× | 240 |
| Mega Drive / Genesis | 320×224 | 3× | 240 |
| Master System | 256×192 | 4× | 180 |
| PC Engine | 256×232 | 3× | 240 |
| Nintendo 64 | 320×240 | 3× | 240 |
| PlayStation | 320×240 | 3× | 240 |
| PlayStation (480i) | 640×480 | 1.5× | 480 |
| Saturn | 320×224 | 3× | 240 |
| Dreamcast | 640×480 | 1.5× | 480 |
| PlayStation 2 | 640×448 | 1.5× | 480 |
| GameCube / Wii | 640×480 | 1.5× | 480 |
| Arcade (CPS) | 384×224 | 3× | 240 |
| Game Boy / Color | 160×144 | 5× | 144 |
| Game Boy Advance | 240×160 | 4.5× | 160 |
| Nintendo DS (one screen) | 256×192 | 4× | 180 |
| PSP | 480×272 | 2.5× | 288 |
| Game Gear | 160×144 | 5× | 144 |
| Neo Geo Pocket | 160×152 | 5× | 144 |
| WonderSwan | 224×144 | 5× | 144 |

Where the exact value is not round (SNES: 720 / 224 = 3.21) the nearest whole number is used, so every scanline stays equally thick. Use **Manual** for other setups.
