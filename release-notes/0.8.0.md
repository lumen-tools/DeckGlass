### New
- **Save states.** Store the shader, source resolution and all parameters under a name of your choice – DeckGlass suggests one like `retro-crisis-ps2-dirty-1.5x`. Load them from a dropdown, replace them by saving under the same name, or delete them. Per-game settings remember the loaded save state.

### Changed
- **Parameters work like in ShaderGlass:** changes stay as long as you keep the shader, also across restarts, and reset to the shader's defaults when you choose another shader or save state. To keep a set of parameters, save a state.
- Per-game settings keep their parameters as before.

### Install
Download `DeckGlass-0.8.0.zip` below → Decky → Developer → **Install Plugin from ZIP**.
