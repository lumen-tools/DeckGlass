First public **beta** of DeckGlass – RetroArch and Retro Crisis shaders for every game on the Steam Deck, via gamescope ReShade.

### Highlights
- Converts RetroArch slang presets (`.slangp`) into a single ReShade effect on the Deck – multi-pass, feedback, history, LUTs and parameters included
- Two libraries in a file browser: **RetroArch** (libretro slang-shaders) and **RetroCrisis** (Retro Crisis GDV-NTSC, incl. "720p Steam Deck")
- Source resolution presets per system with the resulting pixel size, or a manual pixel size
- Per-game settings, "Only in games" mode, parameter dialog with value legends
- Optional OLED defringe (Deck OLED only)
- Crash guard: a shader that crashes gamescope is turned off automatically

### Install
1. Enable developer mode in Decky.
2. Download `DeckGlass-0.1.0.zip` below.
3. Decky → Developer → **Install Plugin from ZIP**.

### Known limitations
- A few RetroArch presets cannot be converted (the plugin shows an error).
- Heavy presets (e.g. crt-royale) cost a lot of GPU time.
- Screenshots do not include the shader.
