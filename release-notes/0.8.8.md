### Improved
- **Bilinear filtering now works like "bilinear in the emulator".** With ShaderGlass, shaders look closest to RetroArch when the emulator itself uses bilinear filtering. DeckGlass now does the equivalent on its own: when scaling the game image down to the source resolution it averages the whole area of each original pixel instead of a 2×2 spot.
  - In a test with a 320×240 picture scaled up 3.33× by the "emulator", the reconstruction is about 4× closer to the original at pixel sizes 3.0 and 3.3, and no pixel is picked up wrongly any more (before: 16–18 %, which showed as mosaic patterns).
  - Very fine 1-pixel patterns (dithering) blend a little, like on a real CRT and like the ShaderGlass approach.
- Still one switch: **Bilinear filtering** on/off.
