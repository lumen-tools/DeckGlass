Update with better image quality.

### New
- **Bilinear filtering** (on by default) under Source Resolution. The game image is smoothed while it is scaled down to the source resolution, which usually looks much closer to RetroArch. It can be turned off and stored per game.
- **Emulated mipmaps.** gamescope cannot use mipmaps, so shaders that read mip levels got wrong values – crt-geom-deluxe, for example, takes the average brightness of the picture from the smallest mip level (for its raster bloom and glow) and read a single corner pixel instead. DeckGlass now builds the mip chain itself when a shader needs it. This fixes crt-geom-deluxe and 27 other presets.

### Changed
- Choosing **Presets** under Source Resolution opens the list of systems right away; the chosen system is shown as a button that reopens the list.
- Controls no longer lock while a shader is being converted, so the menu no longer jumps back to the top.

### Install
Download `DeckGlass-0.2.2.zip` below → Decky → Developer → **Install Plugin from ZIP**.
