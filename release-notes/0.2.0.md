First regular release of DeckGlass – RetroArch and Retro Crisis shaders for every game on the Steam Deck, via gamescope ReShade. Still 0.x: it works well in testing, but expect rough edges before 1.0.

### New in 0.2.0
- **Custom folder for your own presets.** Copy slang presets (with their folders) to `~/deckglass-shaders` and they appear under **Custom** in the browser. Presets that point to RetroArch's shader folder (`shaders_slang/...`) – presets saved in RetroArch, or a newer Retro Crisis release unpacked there – find those files in the bundled libretro shaders automatically.
- The browser re-scans the folders every time it opens.

### Everything else
- Converts RetroArch slang presets (`.slangp`) into one ReShade effect on the Deck – multi-pass, feedback, history, LUTs and parameters
- Three libraries in a file browser: **RetroArch**, **RetroCrisis** (incl. "720p Steam Deck") and **Custom**
- Source resolution per system with round pixel sizes and a **Black bars top & bottom** switch (800 or 720 lines), or a manual pixel size
- Per-game settings, "Only in games" mode, parameter dialog that explains numbered values
- Optional OLED defringe (Deck OLED only)
- Crash guard: a shader that crashes gamescope is turned off automatically

### Install
1. Enable developer mode in Decky.
2. Download `DeckGlass-0.2.0.zip` below.
3. Decky → Developer → **Install Plugin from ZIP**.

### Known limitations
- Some RetroArch presets cannot be converted (the plugin shows an error).
- Heavy presets (e.g. Retro Crisis) cost GPU time and add some latency; gamescope also has to composite every frame while an effect is active.
- Screenshots do not include the shader.
