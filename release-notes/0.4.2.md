### Fixed
- **Round pixel sizes again.** 0.4.0 calculated exact factors from the height of the game picture, which gave values like 3.33×, 2.65× or 5.56×. Fractional factors make scanlines uneven, so the pixel size is now always round again – while the detection of 720 or 800 lines from 0.4.0 stays:

| System | Game renders 720 lines | Game renders 800 lines |
|---|---|---|
| 240p | 3× | 3× |
| 480i/p | 1.5× | 1.5× |
| Game Boy / Color, Game Gear, WonderSwan | 5× | 6× |
| Game Boy Advance | 4.5× | 5× |
| Nintendo DS | 4× | 4× |
| PSP | 2.5× | 2.5× |
| Neo Geo Pocket | 5× | 5× |
