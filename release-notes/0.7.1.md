### Changed
- **720p / 800p choice** under Source Resolution replaces the "Black bars top & bottom" switch. It picks which pixel sizes the system presets use – try both and see what looks better for each game and shader:

| System | 720p | 800p |
|---|---|---|
| 240p | 3× | 3.3× |
| 480i/p | 1.5× | 1.7× |
| Game Boy / Color, Game Gear, WonderSwan | 5× | 5.6× |
| Game Boy Advance | 4.5× | 5× |
| Nintendo DS | 3.8× | 4.2× |
| PSP | 2.6× | 2.7× |
| Neo Geo Pocket | 4.7× | 5.3× |

  720p is the default; it usually gives the most even scanlines. Existing settings and per-game profiles start on 720p.

### Fixed
- **No false crash warning after a restart.** With a global shader, restarting the Deck showed "gamescope crashed" although the shader was only turned off as intended. The crash guard now only watches the main gamescope process and ignores anything left over from before a restart.
